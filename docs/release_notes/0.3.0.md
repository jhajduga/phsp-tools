# PHSP Tools v0.3.0

First public release of the integrated C++ toolkit for IAEA phase-space preparation,
ROOT analysis and source comparison.

## Included applications

- `phspCutter`: configurable rectangular aperture selection with history preservation.
- `phspMerger`: ordered merging of independent IAEA sources with compatible extras.
- `phspToRootMT`: ordered multithreaded IAEA-to-ROOT conversion and provenance.
- `phspAnalyze`: RDataFrame distributions, correlations, beam statistics and scored histories.
- `phspCompare`: per-species distribution comparisons and quantitative shape distances.
- `phspPipeline`: JSON preparation, conversion, analysis and comparison workflows.

## Analysis and documentation

Particle analyses default to straight-line projection to Z=100 cm under a shared,
target-centred +Z convention. This is a geometric vacuum model. Each report describes
its source geometry, selected plane, quality checks and history limitations.

Reports and documentation are in English, with separate figure sections for particle
species. The repository includes an mdBook, synthetic tests, MIT licensing and citation
metadata with downloadable BibTeX and plain-text references.

## Installation and assets

This release distributes **source code**, not standalone prebuilt binaries. Building
requires C++20, CMake, ROOT 6.34 or newer, fmt and nlohmann/json. The repository includes
a Conda environment and build/test presets.

Assets include source archives, citation files, licence, these notes and SHA-256 checksums.
PHSP datasets and generated analysis outputs are not included in the source archives.
